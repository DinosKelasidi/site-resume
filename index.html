сопроводительное письмо

Frontend-разработчик, более года коммерческого опыта. Занимаюсь версткой и разработкой интерфейсов: от простых лендингов до адаптивных многостраничных сайтов под все устройства и breakpoints, с подходом mobile-first. Разрабатываю при помощи таких технологий как HTML5, CSS3, SCSS, JS, TypeScript на базе таких библиотек и фреймворков как React и Vue. Собираю интерфейсы из переиспользуемых компонентов, слежу за типизацией и чистотой кода, использую BEM-методологию для предсказуемой структуры стилей. Плотно работаю с макетами в Figma, реализую сложные интерактивные состояния и фичи — burger-menu, многошаговый Stepper, адаптивные Grid- и Flex-раскладки — и слежу за тем, чтобы интерфейс не «ломался» ни на одном из брейкпоинтов. На проектах настраивал ESLint / Prettier для единого стиля кода в команде.

проект — react landing

Лендинг для SaaS-продукта на React — многостраничный сайт с посадочной страницей, страницей тарифов, блогом и формой заявки.

1UI-KIT

  • Реализовал переиспользуемый UI-kit: Button, Input, Card, Modal, Badge
  • Единый API пропсов для всех компонентов
  • Проработал состояния: default / hover / focus / disabled
  • Строгая типизация через TypeScript

2LAYOUT-КОМПОНЕНТЫ

  • На основе UI-компонентов собрал переиспользуемые layout-блоки: Header, Sidebar, Footer, Section
  • Используются на всех страницах без дублирования разметки и стилей

3НАВИГАЦИЯ

  • Навигация между страницами реализована на React Router

4ОПТИМИЗАЦИЯ ЗАГРУЗКИ

  • Страницы подключены через React.lazy и Suspense
  • Код каждой страницы подгружается отдельным чанком только при переходе на неё
  • Это уменьшило вес начального бандла и ускорило первую отрисовку

5ВЁРСТКА И СТИЛИ

  • На Flexbox / CSS Grid
